# 구글 드라이브 연결 설정 가이드

Yobsidian이 내 구글 드라이브에 접근하려면 **내 구글 계정에서 직접 만든 OAuth 클라이언트 ID**가 필요해요.
개인용이라 한 번만 만들면 되고, 비용은 들지 않아요. 10분 정도 걸려요.
(콘솔 화면 이름은 구글이 가끔 바꿔요. 이름이 조금 달라도 같은 메뉴를 찾으면 돼요.)

## 1. 프로젝트 만들기

1. <https://console.cloud.google.com/projectcreate> 에 접속해 로그인합니다.
2. 프로젝트 이름에 `Yobsidian`을 넣고 **만들기**를 누릅니다.
3. 위쪽 프로젝트 선택 상자에서 방금 만든 프로젝트가 선택돼 있는지 확인합니다.

## 2. Google Drive API 켜기

1. <https://console.cloud.google.com/apis/library/drive.googleapis.com> 으로 갑니다.
2. **사용** 버튼을 누릅니다.

## 3. 동의 화면 설정

1. <https://console.cloud.google.com/auth/overview> (Google 인증 플랫폼)에서 **시작하기**를 누릅니다.
2. 앱 이름은 `Yobsidian`, 지원 이메일은 내 이메일을 고릅니다.
3. 대상(Audience)은 **외부(External)** 를 고릅니다. (개인 Gmail 계정은 이것만 선택할 수 있어요.)
4. 연락처 이메일을 넣고 약관에 동의한 뒤 **만들기**.
5. **대상(Audience)** 메뉴에서 **테스트 사용자**에 내 구글 계정 이메일을 추가합니다.
6. **데이터 액세스(Data Access)** 메뉴에서 **범위 추가 또는 삭제**를 눌러 아래 범위를 추가합니다.
   `https://www.googleapis.com/auth/drive` (Google Drive의 모든 파일을 확인, 수정, 생성, 삭제)

> **왜 `drive` 전체 범위인가요?** 더 좁은 `drive.file` 범위는 앱이 직접 만든 파일만 볼 수 있어서, 이미 옵시디언으로 쓰던 볼트 폴더를 그대로 열 수 없어요.
> 이 범위는 구글이 "민감한 범위"로 분류해서, 아래 4번의 경고 화면이 한 번 나와요. 내 프로젝트를 내 계정으로만 쓰는 거라 괜찮아요.

### 7일마다 다시 로그인하게 되는 문제

동의 화면의 **게시 상태**가 "테스트 중"이면 구글이 **7일마다 로그인을 만료**시켜요.
귀찮으면 **대상(Audience) → 앱 게시(Publish app)** 를 눌러 "프로덕션"으로 바꾸세요.
검증을 받지 않은 앱이라 로그인할 때 "확인되지 않은 앱" 경고가 나오지만, 내가 만든 앱이니 **고급 → Yobsidian(안전하지 않음)으로 이동**을 누르면 되고, 그 뒤로는 만료되지 않아요.

## 4. 클라이언트 ID 만들기

<https://console.cloud.google.com/auth/clients> → **클라이언트 만들기**. 쓰려는 플랫폼에 맞춰 만드세요. 둘 다 써도 됩니다.

### 웹용 (브라우저)

- 애플리케이션 유형: **웹 애플리케이션**
- **승인된 JavaScript 원본**에 앱을 여는 주소를 넣습니다.
  - 개발할 때: `http://localhost:1420`
  - 배포했다면: `https://내아이디.github.io` 처럼 주소창에 보이는 origin (경로 `/…`는 빼고)
- 리디렉션 URI는 비워 둬도 돼요.
- 만들면 나오는 **클라이언트 ID**를 복사합니다. (웹에서는 보안 비밀이 필요 없어요.)

> 웹에서는 구글이 한 번에 한 시간짜리 토큰만 줘요(서버가 없는 앱의 한계). 한 시간이 지나면 상태 표시줄에 "다시 로그인 필요"가 뜨고, 화면 아무 곳이나 한 번 누르면 조용히 다시 연결돼요. 구글 로그인 팝업이 뜨면 허용해 주세요.

### 데스크톱용 (윈도우·맥)

- 애플리케이션 유형: **데스크톱 앱**
- 만들면 나오는 **클라이언트 ID**와 **클라이언트 보안 비밀**을 둘 다 복사합니다.
  (설치형 앱의 "보안 비밀"은 구글 정책상 비밀로 취급되지 않지만, 토큰을 받을 때 필수예요.)
- 데스크톱 앱은 로그인할 때 시스템 브라우저를 열고, 내 컴퓨터의 `127.0.0.1` 임시 포트로 결과를 돌려받아요. 따로 등록할 주소는 없어요.
- 한 번 로그인하면 갱신 토큰이 **운영체제 키체인**(맥 키체인 / 윈도우 자격 증명 관리자)에 저장돼서 다시 로그인할 필요가 없어요.

## 5. 앱에 입력하기

두 가지 방법 중 편한 쪽을 고르세요. 앱에서 입력한 값이 환경 변수보다 우선해요.

**방법 A. 앱 안에서 입력 (설치형 앱에 추천)**
상태 표시줄 왼쪽 아래의 **☁ 동기화 꺼짐**을 누르면 "클라이언트 ID" 입력란이 나와요. 값을 붙여 넣고 저장하세요.

**방법 B. 빌드할 때 넣기**
프로젝트 폴더에 `.env.local` 파일을 만들고 (git에 올라가지 않아요) 아래처럼 적습니다. 개발 서버와 빌드 모두에 적용돼요.

```bash
VITE_GOOGLE_CLIENT_ID=1234567890-abcdefg.apps.googleusercontent.com
# 데스크톱 앱 빌드에만 필요해요. 웹으로 배포하는 빌드에는 넣지 마세요 (번들에 그대로 들어가요).
VITE_GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxxxx
```

## 6. 로그인하고 폴더 고르기

1. ☁ 버튼 → **Google로 로그인** → 구글 화면에서 허용합니다.
2. **드라이브 폴더 고르기**에서 볼트로 쓸 폴더를 고르거나 새로 만듭니다. (내 드라이브 전체는 고를 수 없어요.)
   - 이미 노트가 들어 있는 폴더를 고르면 내려받고, 내 컴퓨터에 이미 노트가 있으면 양쪽을 합쳐요. 같은 이름인데 내용이 다르면 둘 다 남겨요.
3. 그다음부터는 앱이 열려 있는 동안 1분마다, 그리고 노트를 고친 직후와 창으로 돌아올 때마다 자동으로 맞춰요.

데스크톱에서 옵시디언 볼트 폴더를 그대로 쓰려면 ☁ 대화 상자의 **폴더 열기…** 로 그 폴더를 고른 다음, 같은 대화 상자에서 드라이브 폴더를 연결하세요.

## 문제 해결

| 증상 | 원인과 해결 |
| --- | --- |
| `redirect_uri_mismatch` 또는 `origin_mismatch` | 웹용 클라이언트의 **승인된 JavaScript 원본**에 지금 주소가 없어요. 3번 항목처럼 정확한 origin(`http://localhost:1420` 등)을 추가하고 몇 분 기다리세요. |
| `access_denied` / "앱이 차단됨" | 동의 화면의 **테스트 사용자**에 로그인하려는 계정이 없어요. 추가하세요. |
| `invalid_client` | 클라이언트 ID가 틀렸거나, 데스크톱 앱인데 보안 비밀이 비어 있어요. |
| 일주일쯤 지나 "로그인이 만료됐어요" | 동의 화면이 "테스트 중"이에요. 3번의 "앱 게시"를 하거나, 일주일마다 다시 로그인하세요. |
| 웹에서 로그인 팝업이 안 떠요 | 브라우저가 팝업을 막았어요. 주소창 오른쪽의 팝업 차단 아이콘에서 허용하세요. |
| 맥에서 앱이 "손상됨" 또는 "확인되지 않은 개발자" | 서명하지 않은 앱이라 그래요. Finder에서 우클릭 → 열기, 또는 `xattr -dr com.apple.quarantine /Applications/Yobsidian.app` |

## 동기화가 하는 일, 하지 않는 일

- 양쪽 중 **한쪽만** 바뀐 노트는 바뀐 쪽으로 맞춰요. 양쪽이 **다른 부분**을 고쳤으면 줄 단위로 자동 병합해요.
- 같은 줄을 양쪽에서 고쳤으면 내 컴퓨터 버전을 그 자리에 두고, 드라이브 쪽 버전은 `노트 (충돌 2026-10-06 1530).md` 로 옆에 저장해요. 어떤 것도 덮어써서 사라지지 않아요.
- 지운 파일은 내 컴퓨터에서는 `.trash/` 폴더로, 드라이브에서는 휴지통(30일 보관)으로 가요. 한 번에 너무 많이(전체의 절반 넘게, 20개 이상) 지워지게 되면 멈추고 물어봐요.
- 동기화하지 않는 것: `.trash/`, `.git/`, `.obsidian/workspace.json`(창 배치), 구글 문서·시트 같은 구글 전용 파일.
- 이름만 바꾼 파일은 "지우고 새로 만든" 것으로 처리돼요. 결과는 같지만 드라이브에서는 새 파일로 보여요.
- 구글 드라이브에는 같은 폴더에 같은 이름의 파일이 여러 개 있을 수 있어요. 이럴 때는 먼저 만든 것만 동기화하고 "문제가 있는 파일"에 알려 줘요.
- 윈도우·맥은 대소문자를 구분하지 않아서, 드라이브에 `a.md`와 `A.md`가 같이 있으면 한쪽이 덮이지 않도록 이름을 바꿔 주세요.
